# Automation contracts

Browser-safe, versioned runtime target policy shared by the spell compiler and
runtime. Version `0.1.0`, Node `>=22.12`.

The package provides the enforced `arcane-dnd5e-2014` runtime profile,
requirement description, binding checks, semantic hashing and runtime adapter
registries. It contains no Foundry hooks, content catalogue, spell descriptions
or Node-only runtime dependency.
